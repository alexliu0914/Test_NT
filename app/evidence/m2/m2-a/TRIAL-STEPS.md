# M2-a 試用步驟（編輯器）

在 M1 試用的環境（Windows、Docker Desktop）上進行；兩個瀏覽器（例如 Chrome 與 Edge）各登入一個帳號。

## 準備

```powershell
cd app
git pull
npm ci
npm run dev        # 網頁
npm run collab     # 協作伺服器（另開一個終端機）
```

## 步驟與預期結果

| # | 操作 | 預期 |
| --- | --- | --- |
| 1 | 在新頁面輸入「/」 | 出現繁體中文選單：標題 1～3、內文、項目清單、編號清單、待辦清單、引言、分隔線、程式碼、表格、頁面連結；沒有圖片、影片等尚未支援的項目 |
| 2 | 在空白行分別輸入「# 」「## 」「- 」「1. 」「[] 」「> 」 | 依序變成標題 1、標題 2、項目清單、編號清單、待辦清單、引言 |
| 3 | 選取文字，用工具列設定粗體、斜體、刪除線、程式碼、連結；連結輸入 `javascript:alert(1)` | 一般格式正常；`javascript:` 連結不會建立 |
| 4 | 拖曳區塊左側的把手，改變區塊順序 | 順序改變；另一個瀏覽器同步看到 |
| 5 | 輸入「/頁面連結」，選另一個頁面 | 出現連結區塊，顯示目標頁面的圖示與標題；點擊直接開啟該頁面 |
| 6 | 把步驟 5 的目標頁面移到垃圾桶，再回來看連結 | 連結顯示「無法開啟的頁面」，不顯示原標題、不能點；從垃圾桶還原後恢復 |
| 7 | 從一般網頁複製一段含連結與格式的文字，貼上 | 文字、清單、連結保留；網頁上的程式與危險連結不會貼進來 |
| 8 | 兩個瀏覽器開同一頁，同時在同一個空白行輸入：一人「# 甲」、另一人「- 乙」 | 兩人的內容都保留（可能分成兩個區塊）；不會整段消失；短暫出現「正在合併」提示屬正常 |
| 9 | 兩邊都重新整理 | 內容與重新整理前相同；狀態顯示「已儲存」 |

已知限制（記於 FAILURES.md T-M2-02）：頁面剛開啟、第一次同步完成前（通常不到 1 秒）使用斜線選單，選單可能會關閉，需要再輸入一次。
