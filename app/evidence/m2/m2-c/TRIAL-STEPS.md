# M2-c 試用步驟（版本紀錄與本機草稿）

在 M2-b 試用的環境（Windows、Docker Desktop、`notes_dev`、四個帳號、共享一 A／B／C、共享二 B／D／A、「游標測試」在共享一）上進行。A（管理者）、B、C、D 各用一個獨立的瀏覽器視窗。**A 與 C 請用一般視窗**（不要用無痕）：步驟 8～11 要在同一個瀏覽器換帳號、關閉後保留草稿。

## 準備：切換到 M2-c（含資料庫遷移 0003）

```powershell
git fetch origin
git checkout -b m2c origin/m2c   # 已有 m2c 分支時改用：git checkout m2c; git pull
cd app
npm ci
npm run db:migrate               # 套用 0003；套用前自動備份到 app\backups\（畫面會印出 backup 檔名）
npm run build                    # 正式模式建置
npm start                        # 網頁 http://localhost:3000
npm run collab                   # 協作伺服器（另開一個終端機）
```

- 遷移印出 `backup ...dump` 與 `applied 0003_versions.sql` 即成功。若出現 `invalid_restore_refs`，表示舊的還原紀錄有問題，遷移已停止、資料沒有變動，請把訊息貼給我。
- 繼續用正式模式（`npm start`）。四個瀏覽器重新整理即可，不需要重新登入。
- 模擬離線的方法同 M2-b：在該分頁按 F12 → 網路（Network）→ 節流選單改「離線」（Offline）；恢復時改回「不節流」。開發人員工具要保持開著。

## 步驟與預期結果

請在每一步的「結果」欄填「通過」或描述看到的情況。

| # | 操作 | 預期 | 結果 |
| --- | --- | --- | --- |
| 1 | A 在「游標測試」打一行「第一版」，按編輯區右上角「存一版」 | 右上角顯示「已存一版。」 | |
| 2 | A 再打一行「第二版」，按「版本紀錄」 | 右側面板列出剛才的版本，標示「手動」、時間、A 的名字與「保留至」日期（約 90 天後）；說明寫著每 10 分鐘自動存版、保留 90 天 | |
| 3 | 點那一列 | 下方出現唯讀預覽，只有「第一版」，沒有「第二版」；預覽裡不能打字 | |
| 4 | 按「還原到此版本」 | 出現確認視窗，寫著「會將目前文件恢復到所選版本；未同步內容可能移入衝突副本」；按「還原」後 A 與 B 的文件 2 秒內都只剩「第一版」，A 顯示「已還原到所選版本。」 | |
| 5 | A 點回文件按幾次 Ctrl+Z | 「第二版」不會回來（還原後的復原不會覆蓋還原） | |
| 6 | A 再開「版本紀錄」 | 多一列「還原前」版本，下方有一筆還原紀錄；點「還原前」預覽看得到「第二版」，還原它之後 A、B 的文件回到「第一版＋第二版」 | |
| 7 | A 打幾個字後關閉這一頁（或切到別頁），等 11 分鐘再開「版本紀錄」 | 出現標示「自動」的版本（頁面關著也會存）；手動、自動、還原前的標示不同 | |
| 8 | B 用 F12 模擬離線，在「游標測試」打「B 離線」；A 從「版本紀錄」還原到任一版本；B 改回不節流 | B 的「B 離線」**不會**出現在文件中；A 的「版本紀錄」多一個「衝突副本」，預覽看得到「B 離線」，按「複製內容」可以複製；B 之後打的字正常同步 | |
| 9 | A 沒有任何未同步修改時，到「設定」按「登出」 | 直接登出到登入頁 | |
| 10 | A 重新登入，打開「游標測試」，F12 模擬離線打「A 草稿」；到「設定」按「登出」 | 先顯示「正在同步…（最多 10 秒）」，10 秒後出現「還有尚未同步的修改」，有：繼續等待、下載未同步內容（JSON）、保留草稿並登出、捨棄修改並登出、取消 | |
| 11 | 依序按：下載（打開 JSON 看得到「A 草稿」，沒有密碼或憑證）→ 取消（仍在設定頁）→ 再按登出 → 保留草稿並登出 | 保留前出現共用裝置警告（「資料仍留在此瀏覽器裝置…」）；確認後登出 | |
| 12 | 在 A 的同一個瀏覽器改用 C 登入（關掉開發人員工具或改回不節流），打開「游標測試」；再到「設定」 | C 的文件**沒有**「A 草稿」；C 的設定頁「此裝置上的草稿」只算 C 自己的（0 份未同步），沒有提到其他帳號的草稿 | |
| 13 | C 登出，再用 A 登入、打開「游標測試」 | 「A 草稿」只出現一次，送到伺服器（B 也看到），狀態「已儲存」 | |
| 14 | A 模擬離線打「要捨棄」，登出 → 捨棄修改並登出 | 會再問一次「確定捨棄？」；確認後登出；A 重新登入後「要捨棄」不在文件中 | |
| 15 | A 在「設定 → 此裝置上的草稿」按「刪除我在這台裝置的草稿」 | 會再問一次；確認後數量變 0 | |
| 16 | （開發模式，選做）停掉 `npm start` 改用 `npm run dev`，在「游標測試」打字後按 Ctrl+Z、Ctrl+Shift+Z | 復原、重做都有作用（F-M2-12） | |
| 17 | 四個瀏覽器都重新整理 | 內容一致，狀態都是「已儲存」 | |
